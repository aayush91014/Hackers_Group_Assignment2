SMART HOME BAYESIAN NETWORK
Run from this directory: python smart_home_bn.py
Dependencies: Python 3, matplotlib, numpy.
The script defines all CPTs, validates normalization, performs exact enumeration,
calculates Q1-Q7, generates ancestral samples at n=500/5000/20000, learns MLE and
BDeu(ESS=10) parameters, writes CSV comparisons and saves the error plot.
